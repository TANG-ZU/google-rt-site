隐私政策

rt · 最后更新：2026-09-25

本页说明 rt（下称"本应用"）如何访问、使用、存储和共享 Google 用户数据。 本应用是供本人使用而开发的个人工具，没有其他用户。

1. 访问哪些 Google 数据

本应用仅通过 Google OAuth 2.0 申请以下权限，且只申请实现功能所必需的最小范围：

权限（scope） 用途
https://www.googleapis.com/auth/drive.file 创建、读取、更新由本应用创建或经本人通过本应用打开的文件。无法访问云端硬盘中与本应用无关的其它文件。

本应用不申请 Gmail、日历、联系人等其它任何权限，也不读取 Google 账号的密码、支付信息或身份信息。

2. 如何使用这些数据

  • 仅用于在本人的云端硬盘上执行本应用的核心功能（备份、整理、导出等自动化操作）
  • 不会用于广告、用户画像、信用评估，也不会用于训练机器学习模型
  • 不会把数据出售或转让给任何第三方

3. 如何存储数据

  • OAuth 令牌（access token / refresh token）仅保存在运行本应用的这台电脑本地，例如 google_token.json，不会被上传到任何服务器
  • 本应用没有服务器，不收集、不缓存、不持有任何用户数据副本
  • 通过 API 读取的文件内容仅在内存中处理，处理完成后即释放，不落盘留存

4. 数据共享

本应用不与任何第三方共享 Google 用户数据。除为提供上述功能所必需（向 Google Drive API 发起请求）之外，不存在任何数据传输。

5. Google API 服务用户数据政策

本应用对从 Google API 获取的信息的使用，遵循 Google API Services User Data Policy， 包括其 Limited Use 要求。

rt's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. 数据的保留与删除

  • 撤销授权：随时访问 Google 账号权限页 移除本应用的访问权，本应用将立即无法再访问任何数据
  • 删除本地令牌：直接删除本机的令牌文件（如 google_token.json）即可
  • 由于本应用不在任何服务器上留存数据，撤销授权并删除本地文件后，不残留任何数据的副本
  • 修改 Google 账号密码也会使已签发的令牌失效

7. 儿童隐私

本应用不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

8. 政策变更

本政策如有更新，将直接修订本页面并更新页首的"最后更新"日期。
